What happens next

in order
  1. The subject is trimmed of Re:, Fwd: and similar, then matched to an open thread in the same mailbox.
  2. Rules read the text and pick one route: needs reply, waiting, FYI, newsletter or receipt.
  3. A local two-sentence summary is written from the latest inbound message.
  4. The priority score is computed and the reason is shown on the row.

A VIP sender always lands in “Needs reply” unless the mail is clearly bulk or a receipt.

Threading

safe by default

A message joins an existing thread when the cleaned subject and mailbox match and the thread is not closed. A Message-ID that was already imported is skipped, so importing the same file twice does not duplicate it.

Conversation history stays in order Closed threads start a new thread Nothing leaves this machine

No credentials

by design

Switchboard has no IMAP, OAuth or SMTP code. There is no password field for a mailbox because there is no mailbox connection. That keeps the desk useful without asking you to hand over an app password.
