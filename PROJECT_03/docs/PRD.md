# PRD: Daily Review Agent (Project 03)

## 1. Problem

Days end abruptly. Unfinished tasks silently roll over, the same blockers come back week after
week, and tomorrow starts without a plan. People who try a written end-of-day review give up
because it takes 20 minutes of staring at a blank page.

## 2. Target users

Individual contributors, students and freelancers who manage their own work and want a short,
repeatable shutdown ritual, plus a weekly picture of how they actually work.

## 3. Use cases

1. During the day, add tasks and quickly log what was done, wins, learnings and blockers.
2. At the end of the day, run a five-minute review: see the recap, decide what happens to each
   unfinished task, resolve or keep blockers, record energy and focus.
3. Get a written review: a recap paragraph, honest blockers summary and a realistic plan for
   tomorrow (top priorities that fit the available time).
4. Commit the plan: tomorrow's tasks are scheduled and ordered.
5. Look back: past reviews by date and weekly trends (completion, carry-over, focus, energy,
   recurring blockers, review streak).

## 4. MVP scope

| Area | Feature |
|---|---|
| Accounts | Register / sign in / sign out, private data, per-user timezone and daily capacity (hours) |
| Today | Tasks for today (todo / in progress / done), quick add with estimate and area, work log (done / win / learning / note), blockers (open / resolve), energy, mood and focus check-in |
| Daily recap | Automatically assembled from today's completed tasks, log entries and time |
| Blockers | Persist across days until resolved; age shown; recurring blocker detection |
| Tomorrow plan | Carry over / drop / reschedule each unfinished task; plan is ranked by priority, due date, age and estimate, and capped at the user's capacity; "commit plan" schedules tasks for tomorrow |
| Review | Generated by Claude when `ANTHROPIC_API_KEY` is set (structured JSON, validated, may only plan existing tasks); otherwise a deterministic rule-based review, labelled |
| Weekly trends | Last 7/14 days: tasks completed per day, carry-over rate, focus hours, energy and mood line, blockers opened vs resolved, review streak, time by area |
| History | Every saved review, by date |

## 5. Out of scope (future)

Calendar import, team sharing, email/Slack delivery of the review, mobile app, Pomodoro timer.

## 6. User stories

- *As a user,* I can log "fixed the login bug" as done work in two seconds.
- *As a user,* at 6pm I open Review and see what I did today without typing it again.
- *As a user,* I decide for each unfinished task: tomorrow, later date or drop.
- *As a user,* I get tomorrow's top priorities that fit my 6 available hours.
- *As a user,* I see that "waiting for API access" has blocked me on 4 of the last 7 days.
- *As a user,* I see my completion and carry-over trend for the week.

## 7. Key flows

1. **During the day:** Today → add tasks / log entries / blockers (inline, no page reloads).
2. **Shutdown:** Review → recap (auto) → triage unfinished tasks → blockers → check-in →
   Generate review → read plan → **Commit plan** → done (streak +1).
3. **Reflect:** Trends (weekly charts) and History (past reviews).

## 8. Non-functional requirements

- Single Python process, SQLite, no JavaScript build; works without JavaScript (forms degrade to
  full page loads), HTMX enhances with partial updates.
- Session cookie + synchronizer CSRF token for every form/HTMX request.
- All charts server-rendered as accessible inline SVG (with text equivalents).
- AI optional, labelled, never sees other users' data; tests never call paid APIs.

## 9. Success criteria

- The end-of-day review takes under five minutes with a populated day.
- Tomorrow's plan never exceeds the configured capacity and only contains real tasks.
- Trends are correct for the user's timezone day boundaries.
