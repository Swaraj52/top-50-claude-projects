# Top 50 Claude Projects

A portfolio of 50 independently runnable software applications, built one at a time from the
*Top 50 Claude Project Ideas* list. The projects span personal productivity, business operations,
marketing, learning, finance, developer tooling and team/community work.

Each project lives in its own folder with its own dependencies, database, tests and documentation.
Projects are built in the original order, and a project only counts as complete after its core
features have been run and tested.

## How this repository is organized

```text

├── shared-resources/          ← documented shared utilities and doc tooling
└── recovery/                  ← session-recovery state (current state, next actions, blockers)
```

## Running a project

Every project is independent. Open its folder and follow its README. The general pattern:

1. Install the toolchain the project lists (most projects use Python 3.11+ and/or Node.js 20+).
2. Copy `.env.example` to `.env` and fill in any values you want to use. Optional integrations
   such as AI features stay switched off until you provide your own key.
3. Install dependencies inside the project folder (a per-project Python virtualenv and/or `npm install`).
4. Run the project's test command, then its start command.

Each project reserves its own ports (backend `80NN`, frontend `51NN`, where `NN` is the project
number), so several can run at the same time. See
[ARCHITECTURE_OVERVIEW.md](ARCHITECTURE_OVERVIEW.md#port-allocation).

## AI features

Projects use AI only where it clearly helps. Integrations call real model APIs through
credentials you provide in a local `.env`, and are never faked. Where a project has a non-AI
fallback, the interface labels it as such. No API keys are stored in this repository.
